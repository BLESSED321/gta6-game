Leonida Nights — a playable GTA-style open-city game set in Leonida: drive the city, take on 4 missions, earn money, keep an eye on your health and the police wanted stars. Minimap, speedometer, and press R to restart.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser. Node 22 or later, no build step and no dependencies.
